# Zotero 双语 PDF 翻译

为 Zotero 10 的 PDF 附件生成逐页配对的双语 PDF：每一页原 PDF 保持不变，后面紧跟该页的简体中文译文页。

## 安装

1. 运行 `npm install && npm run package`。
2. 在 Zotero 中打开“工具 → 插件”，点击齿轮并选择“从文件安装插件”。
3. 选择 `dist/zotero-bilingual-translator-1.0.1.xpi`。
4. 在“设置 → 双语 PDF 翻译”中填写 DeepSeek API Key。

## 使用

在 Zotero 主窗口选择一个 PDF 附件，右键菜单选择“生成中英双语 PDF”。插件会按页提取文本并调用 DeepSeek，只把文字发送给翻译服务。结果保存在原 PDF 同一目录，文件名为 `原文件名.bilingual-zh-CN.pdf`；如有同名文件，自动增加序号。生成成功后，新 PDF 会作为同一父条目的链接附件出现。

输出页序为：原文第 1 页、其中文译文页、原文第 2 页、其中文译文页……原页面通过 PDF 页面复制保留。译文页会依据 Zotero 的结构化版面分析，按阅读顺序放置中文段落以及从原 PDF 裁剪的图片、独立公式和整张表格；图注会翻译。视觉元素保持宽高比例，空间不足时整体移至下一页。

若当前 PDF 无法生成结构化版面，插件会自动回退到纯文本译文页，并在完成提示中明确显示“已回退为纯文本译文”。

## 限制与隐私

- 仅支持具有可提取文字的 PDF；扫描件和受密码保护文件不支持。
- 文档段落会发送到 DeepSeek API，请确认其适合你的资料保密要求。
- 原页面会完整保留，但插件不翻译图片或表格内部文字，也不把公式转换为可编辑格式。
- 独立公式可通过原 PDF 区域保留；行内公式属于尽力保留，复杂数学字体可能无法准确处理。
- 中文译文页采用可读性优先的单栏排版，不重建原文的复杂表格或双栏布局。
- 翻译缓存当前只在 Zotero 进程内保留；关闭 Zotero 后重新运行会重新请求尚未写入的内容。
