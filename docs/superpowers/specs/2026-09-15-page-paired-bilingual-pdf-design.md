# Zotero 原文页与译文页双语 PDF 设计

## 目标

升级现有 Zotero 双语 PDF 翻译插件。生成文档时完整保留原 PDF 的每一页，并在该页之后插入对应的简体中文译文页。图片、公式、表格、图注和原版式均保留在原文页中，只有提取出的文本发送给 DeepSeek 翻译。

## 输出结构

输出按照以下顺序组织：

1. 原 PDF 第 1 页的完整页面。
2. 第 1 页对应的中文译文页；内容过长时可占多页。
3. 原 PDF 第 2 页的完整页面。
4. 第 2 页对应的中文译文页。
5. 依此类推，直至文档结束。

原文页以矢量 PDF 页面直接嵌入新文档，不转换成图片，避免降低图片与公式质量。译文页采用 A4 可读性排版，并在页眉显示“原文第 N 页译文”。

## 文本提取与翻译

- 使用 Zotero PDF Worker 或其底层 PDF.js 能力按页提取文本。
- 每页文本按 PDF 阅读顺序整理；双栏页面按左栏从上到下、再右栏从上到下处理。
- 只有文本内容发送给 DeepSeek。原始 PDF 页面、图片和公式图像不上传。
- 翻译请求保留公式编号、引用编号、URL、代码和术语；译文页不重复渲染原文中的图片或公式。
- 没有可提取文本的页面只保留原文页，不创建空译文页。

## PDF 合并

- 使用 `pdf-lib` 读取原 PDF，并通过 `copyPages` 将每张原文页原样复制到输出文档。
- 每复制一张原文页，立即创建该页的中文译文页。
- 原文页保持原始尺寸、方向、矢量图形、字体和嵌入图片。
- 译文超出一页时自动续页，然后再插入下一张原文页。
- 原文件不修改；输出仍使用 `*.bilingual-zh-CN.pdf` 命名并写入原目录。

## 进度与取消

进度窗口显示以下阶段：

- 正在分析 PDF 页数。
- 正在提取第 N/M 页文本。
- 正在翻译第 N/M 页。
- 正在合并第 N/M 页。
- 正在保存并添加附件。

取消时停止后续翻译与合并，不生成最终 PDF；已完成的翻译缓存继续保留。

## 错误处理

- PDF 加密、损坏或无法读取时显示明确错误。
- 某页没有文字不视为失败，只跳过其译文页。
- 单页翻译临时失败时遵循现有重试策略；最终失败则终止，不留下半成品。
- 原 PDF 页面复制失败时终止生成，避免输出缺页文档。

## 测试与验收

- 单页 PDF：输出包含一张原文页和至少一张译文页。
- 多页 PDF：验证顺序严格为原文页 N、译文页 N、原文页 N+1、译文页 N+1。
- 含图片、公式、表格的 PDF：原文页视觉和页面尺寸保持不变。
- 无文字页面：保留原页且不插入空译文页。
- 长译文：可以跨多张译文页，下一张原文页顺序不乱。
- 取消与失败：不写出最终 PDF，不破坏原附件。

## 非目标

- 不在原文每一行下方插入中文。
- 不识别或重建可编辑公式。
- 不翻译图片中的文字。
- 不重建复杂表格或原文布局。
